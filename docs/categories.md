# Categories

The master list of categories, ordered by **CEFR level** (A1 → A2 → B1 → B2+).
CEFR order doubles as **difficulty order**: earlier = more common / more fundamental.

- Any category with **more than 30 items** splits into **subcategories**.
- **Expressions** can appear inside a relevant category, or be grouped as their own set per level.
- Each category gets its own **data file** (Italian | accepted Spanish) under `docs/data/`.
  Large categories are split across multiple files.

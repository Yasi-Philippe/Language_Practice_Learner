# B1 · If-clauses: the real ones

> *se* + present → present, future or imperative: *se piove, resto a casa* · Italian also allows *se* + future → future: *se studierete, supererete l'esame* (ES never: *si estudiáis…*)

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Se ___, restiamo a casa. | piovere | piove | Si llueve, nos quedamos en casa. | |
| Se hai tempo, ___ al cinema. | andare · noi | andiamo, andremo | Si tienes tiempo, vamos al cine. | |
| Se ___ presto, prendiamo il treno delle otto. | partire · noi | partiamo | Si salimos temprano, cogemos el tren de las ocho. | |
| Se finirai in tempo, ti ___ a cena. | portare · io | porterò | Si terminas a tiempo, te llevaré a cenar. | *se* + future is fine in Italian |
| Se ___ stanco, vai a letto. | essere · tu | sei | Si estás cansado, vete a la cama. | |
| Se vedi Marco, ___ di chiamarmi. | dire · tu + gli | digli | Si ves a Marco, dile que me llame. | imperative in the main clause |
| Se studierete, ___ l'esame. | superare · voi | supererete | Si estudiáis, aprobaréis el examen. | |
| Se non mangi, non ___. | crescere · tu | cresci, crescerai | Si no comes, no creces. | |
| Se ___ bel tempo, andremo al mare. | fare | fa, farà | Si hace buen tiempo, iremos a la playa. | |
| Se mi ___, ti aiuto. | chiamare · tu | chiami | Si me llamas, te ayudo. | |
| Se ___ la macchina, arriviamo prima. | prendere · noi | prendiamo | Si cogemos el coche, llegamos antes. | |
| Se gli scrivi, ti ___ subito. | rispondere · lui | risponde, risponderà | Si le escribes, te contesta enseguida. | |
| Se ___ freddo, accendi il riscaldamento. | avere · tu | hai | Si tienes frío, enciende la calefacción. | |
| Se volete, vi ___ alla stazione. | accompagnare · io | accompagno | Si queréis, os acompaño a la estación. | |
| Se ___ tardi, non aspettatemi. | fare · io | faccio, farò, arrivo, arriverò | Si llego tarde, no me esperéis. | *fare tardi* = llegar tarde |
| Se non ti ___, dimmelo. | piacere | piace | Si no te gusta, dímelo. | |
| Se lo ___, me lo dirà. | sapere · lui | sa, saprà | Si lo sabe, me lo dirá. | |
| Se ___ le chiavi, chiamami. | trovare · tu | trovi | Si encuentras las llaves, llámame. | |
| Se i bambini ___, li porto al parco. | volere | vogliono | Si los niños quieren, los llevo al parque. | |
| Se domani ___, ti telefono. | potere · io | posso, potrò | Si mañana puedo, te llamo. | |

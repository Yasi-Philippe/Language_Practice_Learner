# B1 · Imperative with pronouns & the polite Lei

> *tu, noi, voi*: the pronoun sticks to the end — *dimmi, fallo, andiamoci, scriveteci* · after *da', di', fa', sta', va'* the consonant doubles: *dammi, dimmi, fammi* (but *digli*) · negative *tu*: *non farlo / non lo fare* · *Lei*: subjunctive form, pronoun in front — *mi dica, si accomodi, venga*

Italian sentence with one gap (`___`) → type the missing form, pronouns included. Checked strictly: accents count, capitals don't.
Cue = the verb, who you're talking to, and the pronoun; Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|

| ___ un favore: chiudi la porta. | fare · tu + mi | Fammi | Hazme un favor: cierra la puerta. | |

| Il libro? ___ subito! | leggere · tu + lo | Leggilo | ¿El libro? ¡Léelo enseguida! | |
| Le chiavi? ___ a me! | dare · tu + le | Dalle | ¿Las llaves? ¡Dámelas! | |
| ___ domani, ragazzi! | scrivere · voi + mi | Scrivetemi | ¡Escribidme mañana, chicos! | |

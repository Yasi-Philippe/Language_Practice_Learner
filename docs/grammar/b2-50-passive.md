# B2 · The passive: essere, venire, andare

> *essere* + participle (agreeing): *la casa è stata venduta* · *venire* + participle = it gets done (simple tenses only): *la porta viene chiusa alle otto* · *andare* + participle = it must be done: *il modulo va firmato* · the agent with *da*: *scritto da Calvino*

Italian sentence with one gap (`___`) → type the passive verb. Checked strictly: accents count, capitals don't.
Cue = the verb, and *venire* or *andare* when that's the auxiliary wanted; Spanish = the meaning.
First accepted answer = primary; others are also accepted.

# C1 · Mixed and hidden hypotheticals

> mixed times: *se avessi studiato* (then) → *ora sarei* (now) · *se fossi paziente* (always) → *non avrei litigato* (that time) · no *se* at all: *avessi saputo!, fossi in te, fosse per me, a saperlo, potendo* · spoken Italian: *se lo sapevo, venivo* (= ES *si lo llego a saber, vengo*)

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Se fossi più paziente, ieri non ___. | litigare · io | avrei litigato | Si fuera más paciente, ayer no habría discutido. | permanent condition, past result |
| Se avessi accettato quel lavoro, ora ___ a Londra. | vivere · io | vivrei | Si hubiera aceptado aquel trabajo, ahora viviría en Londres. | past condition, present result |
| Se Luca fosse stato più attento, ora non ___ in ospedale. | essere · lui | sarebbe | Si Luca hubiera tenido más cuidado, ahora no estaría en el hospital. | |
| Se fossi nato in Italia, ___ italiano perfettamente. | parlare · io | parlerei | Si hubiera nacido en Italia, hablaría italiano perfectamente. | |
| Se non avessi perso il portafoglio, ora ___ i soldi per il taxi. | avere · io | avrei | Si no hubiera perdido la cartera, ahora tendría dinero para el taxi. | |
| Se ieri non ___ a letto così tardi, oggi non sarei stanco. | andare · io | fossi andato, fossi andata | Si ayer no me hubiera acostado tan tarde, hoy no estaría cansado. | |
| Se non ci ___ tu, sarei ancora lì. | essere | fossi stato, fossi stata | Si no hubieras estado tú, todavía estaría allí. | |
| Se fosse vero, lo ___ già tutti. | sapere · loro | saprebbero | Si fuera verdad, ya lo sabrían todos. | |
| Se mi ___ prima, ti avrei aspettato. | avvisare · tu | avessi avvisato | Si me hubieras avisado antes, te habría esperado. | |
| ___ saputo prima, sarei venuto! | avere · io | Avessi | ¡Si lo hubiera sabido antes, habría venido! | no *se*: the subjunctive alone |
| ___ in te, ci penserei due volte. | essere · io | Fossi | Yo que tú, me lo pensaría dos veces. | *fossi in te* = yo que tú |
| Fosse per me, ___ subito. | partire · noi | partiremmo | Si fuera por mí, nos iríamos enseguida. | |
| A ___, non sarei uscito. | sapere + lo | saperlo | De haberlo sabido, no habría salido. | *a* + infinitive = if (ES *de* + infinitive) |
| ___, potresti anche venire con noi. | volere · gerund | Volendo | Si quisieras, también podrías venir con nosotros. | gerund as a condition |
| Potendo, ___ subito. | partire · io | partirei | Si pudiera, me iría enseguida. | |
| Studiando di più, ___ l'esame. | superare · tu | avresti superato, avresti passato | Estudiando más, habrías aprobado el examen. | |
| Se ___ dovessi passare da Roma, chiamami. | | mai | Si alguna vez pasaras por Roma, llámame. | *se mai* + *dovessi* = if ever |
| Se lo ___, venivo. | sapere · io · spoken | sapevo | Si lo llego a saber, vengo. | spoken Italian: imperfetto in both halves |
| Se lo vedevo, glielo ___. | dire · io · spoken | dicevo | Si lo llego a ver, se lo digo. | |
| Se avessi un milione, non ___ più. | lavorare · io | lavorerei | Si tuviera un millón, no trabajaría más. | |

# A2 · Imperfetto

> *-are*: -avo, -avi, -ava, -avamo, -avate, -avano (*-evo*, *-ivo* the same) · *essere*: ero, eri, era, eravamo, eravate, erano · *fare → facevo*, *bere → bevevo*, *dire → dicevo*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning (*imperfecto*).
First accepted answer = primary; others are also accepted.

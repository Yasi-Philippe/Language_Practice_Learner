# B1 · Subjunctive or indicative?

> Subjunctive after opinions (*penso, credo, mi sembra*), wishes (*voglio, spero*), feelings (*sono contento*), necessity (*bisogna, è importante*) and *benché, prima che, affinché, senza che* · indicative after certainty: *so che, sono sicuro che, è vero che* · same subject: *penso di* + infinitive

Italian sentence with one gap (`___`) → type the missing form: subjunctive or indicative. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| So che Luca ___ a Milano. | abitare | abita | Sé que Luca vive en Milán. | certainty → indicative |
| Penso che Luca ___ a Milano. | abitare | abiti | Creo que Luca vive en Milán. | opinion → subjunctive (ES indicative!) |
| Sono sicuro che ___ ragione tu. | avere | hai | Estoy seguro de que tienes razón tú. | |
| Mi sembra che ___ un po' stanca. | essere · tu | sia | Me parece que estás un poco cansada. | |
| Credi che ___ vero? | essere | sia | ¿Crees que es verdad? | |
| È vero che Marta ___ incinta? | essere | è | ¿Es verdad que Marta está embarazada? | *è vero che* → indicative |
| È chiaro che lui non ___ niente. | sapere | sa | Está claro que él no sabe nada. | |
| Sappiamo che voi ___ molto. | lavorare | lavorate | Sabemos que trabajáis mucho. | |
| Sono contento che voi ___ qui. | essere | siate | Me alegro de que estéis aquí. | feelings → subjunctive, in both languages |
| Ho paura che non ___ in tempo. | arrivare · noi | arriviamo | Tengo miedo de que no lleguemos a tiempo. | |
| Mi dispiace che tu non ___ venire. | potere | possa | Siento que no puedas venir. | |
| Bisogna che qualcuno ___ con il direttore. | parlare | parli | Hace falta que alguien hable con el director. | |
| Non è sicuro che ___ domani. | piovere | piova | No es seguro que llueva mañana. | |
| Benché ___ tardi, usciamo lo stesso. | essere | sia | Aunque es tarde, salimos igual. | *benché* always takes the subjunctive (ES *aunque* + indicative for facts) |
| Ti telefono prima che tu ___. | partire | parta | Te llamo antes de que te vayas. | |
| Ti spiego tutto affinché tu ___. | capire | capisca | Te lo explico todo para que lo entiendas. | |
| Esco senza che nessuno mi ___. | vedere | veda | Salgo sin que nadie me vea. | |
| Lavoro tanto perché i miei figli ___ studiare. | potere | possano | Trabajo tanto para que mis hijos puedan estudiar. | *perché* = so that → subjunctive |
| Vado a letto presto perché ___ stanco. | essere · io | sono | Me acuesto pronto porque estoy cansado. | *perché* = because → indicative |
| Penso di ___ ragione. | avere · io | avere | Creo que tengo razón. | same subject → *di* + infinitive, no subjunctive |

# A2 · bello, buono, grande, santo

> Before a noun, *bello* changes like the article (*bel, bello, bell', bella, bei, begli, belle*) · *buono* like *un* (*buon, buono, buona*) · *gran* + consonant · *San, Sant', Santo, Santa*

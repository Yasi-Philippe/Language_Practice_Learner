# A2 · Reflexive verbs

> *mi, ti, si, ci, vi, si* + verb · the passato prossimo takes *essere* and agrees: *mi sono alzato/a*, *ci siamo divertiti*

Italian sentence with one gap (`___`) → type the pronoun and the verb. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person or tense when the sentence doesn't say); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Io ___ alle sette. | alzarsi | mi alzo | Me levanto a las siete. | *mi, ti, si, ci, vi, si* + verb |
| A che ora ___? | svegliarsi · tu | ti svegli | ¿A qué hora te despiertas? | |
| Ciao, come ___? | chiamarsi · tu | ti chiami | Hola, ¿cómo te llamas? | |
| Mi ___ Laura. | chiamarsi | chiamo | Me llamo Laura. | |
| Perché ___? | arrabbiarsi · tu | ti arrabbi | ¿Por qué te enfadas? | |
| ___ le mani prima di mangiare. | lavarsi · io | Mi lavo | Me lavo las manos antes de comer. | |
| Marco ___ in fretta. | vestirsi | si veste | Marco se viste deprisa. | |
| Non ___ mai di niente! | ricordarsi · lui | si ricorda | ¡Nunca se acuerda de nada! | |
| Noi ___ sempre alle feste. | divertirsi | ci divertiamo | Siempre nos divertimos en las fiestas. | |
| Voi ___ la doccia ogni mattina? | farsi | vi fate | ¿Os ducháis cada mañana? | *farsi la doccia* = ducharse |
| Voi ___ bene qui? | trovarsi | vi trovate | ¿Estáis a gusto aquí? | *trovarsi bene* = estar a gusto |
| I bambini ___ subito. | addormentarsi | si addormentano | Los niños se duermen enseguida. | |
| Le ragazze ___ per la festa. | prepararsi | si preparano | Las chicas se preparan para la fiesta. | |
| I miei genitori ___ dopo pranzo. | riposarsi | si riposano | Mis padres descansan después de comer. | ES *descansar* isn't reflexive |
| Ieri Paolo ___ tardi. | svegliarsi · pass. prossimo | si è svegliato | Ayer Paolo se despertó tarde. | reflexives take *essere* in the passato prossimo |
| Laura ___ alle sei. | alzarsi · pass. prossimo | si è alzata | Laura se ha levantado a las seis. | the participle agrees: *alzata* |
| Paolo ___ a Milano. | trasferirsi · pass. prossimo | si è trasferito | Paolo se ha mudado a Milán. | |
| Ragazzi, ___ alla festa? | divertirsi · voi · pass. prossimo | vi siete divertiti | Chicos, ¿os habéis divertido en la fiesta? | |
| Io e mia moglie ___ nel 2015. | sposarsi · pass. prossimo | ci siamo sposati | Mi mujer y yo nos casamos en 2015. | |
| Le signore ___ in prima fila. | sedersi · pass. prossimo | si sono sedute | Las señoras se han sentado en primera fila. | *sedersi → seduto* |

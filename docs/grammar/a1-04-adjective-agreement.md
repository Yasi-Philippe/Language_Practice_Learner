# A1 · Adjective agreement

> *-o* adjectives: *-o, -a, -i, -e* · *-e* adjectives: *-e* (m. and f.), plural *-i* · *-co/-go → -chi/-ghi*, *-ca/-ga → -che/-ghe* · *blu, rosa, viola* never change

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the adjective (masculine singular); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

# A1 · Piacere (mi piace / mi piacciono)

> *piace* + one thing or a verb · *piacciono* + plural · *mi, ti, gli* (to him), *le* (to her, polite you), *ci, vi, gli* (to them)

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = who it pleases (when the sentence doesn't say); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Mi ___ la pizza. | | piace | Me gusta la pizza. | one thing → *piace* |
| Mi ___ i gatti. | | piacciono | Me gustan los gatos. | plural → *piacciono* |
| Ti ___ ballare? | | piace | ¿Te gusta bailar? | a verb → *piace* |
| Mi ___ cucinare e mangiare. | | piace | Me gusta cocinar y comer. | verbs → *piace*, even two |
| A Marco ___ il calcio. | | piace | A Marco le gusta el fútbol. | no extra pronoun: *a Marco piace* (ES *le*) |
| Ai miei genitori ___ viaggiare. | | piace | A mis padres les gusta viajar. | |
| A Giulia ___ le rose. | | piacciono | A Giulia le gustan las rosas. | |
| Ai bambini ___ i dolci. | | piacciono | A los niños les gustan los dulces. | |
| A me non ___ le verdure. | | piacciono | A mí no me gustan las verduras. | |
| A loro non ___ il freddo. | | piace | A ellos no les gusta el frío. | |
| Ci ___ le vacanze al mare. | | piacciono | Nos gustan las vacaciones en la playa. | |
| Vi ___ questa città? | | piace | ¿Os gusta esta ciudad? | |
| ___ piace molto Roma. | a me | Mi | Me gusta mucho Roma. | |
| ___ piace il cioccolato? | a te | Ti | ¿Te gusta el chocolate? | |
| ___ piacciono i film d'azione. | a lui | Gli | A él le gustan las películas de acción. | to him = *gli* |
| ___ piace leggere. | a lei | Le | A ella le gusta leer. | to her = *le* |
| Signora, ___ piace il caffè? | a Lei | Le | Señora, ¿le gusta el café? | polite: *Le piace?* |
| ___ piacciono gli spaghetti. | a noi | Ci | Nos gustan los espaguetis. | |

# A1 · Present: essere & avere

> *essere*: sono, sei, è, siamo, siete, sono · *avere*: ho, hai, ha, abbiamo, avete, hanno (the h is silent)

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Io ___ italiano. | essere | sono | Yo soy italiano. | |
| Tu ___ stanco? | essere | sei | ¿Estás cansado? | *essere* covers both *ser* and *estar* |
| Marco ___ a casa. | essere | è | Marco está en casa. | *è* (is) has an accent; *e* = and |
| Noi ___ amici. | essere | siamo | Somos amigos. | |
| Voi ___ di Madrid? | essere | siete | ¿Sois de Madrid? | |

| La lezione ___ alle nove. | essere | è | La clase es a las nueve. | |
| Io e Luca ___ fratelli. | essere | siamo | Luca y yo somos hermanos. | *io e Luca* = noi |
| Che ore ___? | essere | sono | ¿Qué hora es? | Italian asks in the plural: *che ore sono?* |
| Oggi ___ lunedì. | essere | è | Hoy es lunes. | |

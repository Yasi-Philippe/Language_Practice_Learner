# B2 · If-clauses: unreal present and past

> unreal present: *se* + imperfect subjunctive → present conditional (*se avessi tempo, verrei*) · unreal past: *se* + pluperfect subjunctive → past conditional (*se avessi saputo, sarei venuto*) · mixed: *se avessi studiato, ora saprei* · never the conditional after *se*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Se ___ ricco, comprerei una barca. | essere · io | fossi | Si fuera rico, me compraría un barco. | *se* + imperfect subjunctive |
| Se avessi tempo, ___ di più. | leggere · io | leggerei | Si tuviera tiempo, leería más. | → present conditional |
| Se ___, ti aiuterei. | potere · io | potessi | Si pudiera, te ayudaría. | |
| Se fossi in te, non ___. | accettare · io | accetterei | Yo que tú, no aceptaría. | *se fossi in te* = yo que tú |
| Se ___ la verità, saresti più tranquillo. | sapere · tu | sapessi | Si supieras la verdad, estarías más tranquilo. | |
| Se avessimo una macchina, ___ in montagna. | andare · noi | andremmo | Si tuviéramos coche, iríamos a la montaña. | |
| Se i miei genitori ___ qui, sarebbero orgogliosi. | essere | fossero | Si mis padres estuvieran aquí, estarían orgullosos. | |
| Cosa ___ se vincessi alla lotteria? | fare · tu | faresti | ¿Qué harías si ganaras la lotería? | |
| Se ___ meno, staresti meglio. | fumare · tu | fumassi | Si fumaras menos, estarías mejor. | |
| Se potessi scegliere, ___ a Venezia. | vivere · io | vivrei | Si pudiera elegir, viviría en Venecia. | |

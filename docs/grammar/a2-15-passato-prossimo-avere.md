# A2 · Passato prossimo with avere

> *avere* (ho, hai, ha, abbiamo, avete, hanno) + participle: *-are → -ato*, *-ere → -uto*, *-ire → -ito* · with *avere* the participle doesn't change

Italian sentence with one gap (`___`) → type the whole verb (auxiliary + participle). Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning (Spain: *ayer comí*, *hoy he comido*).
First accepted answer = primary; others are also accepted.

# B2 · Passato remoto

> *-are*: -ai, -asti, -ò, -ammo, -aste, -arono · *-ere*: -ei (-etti), -esti, -é (-ette), -emmo, -este, -erono (-ettero) · *-ire*: -ii, -isti, -ì, -immo, -iste, -irono · irregulars: *fui, ebbi, feci, dissi, venni, vidi, presi, nacqui, misi, scrissi, seppi, stetti, diedi*

Italian sentence with one gap (`___`) → type the passato remoto. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |

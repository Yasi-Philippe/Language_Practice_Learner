# B1 · Subjunctive: past

> present subjunctive of *avere / essere* + participle: *che io abbia fatto, che lui sia andato* · something already done, seen from now: *penso che abbia finito* · ES *haya hecho*

Italian sentence with one gap (`___`) → type the whole verb (auxiliary + participle). Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Penso che Marco ___ il treno delle otto. | prendere | abbia preso | Creo que Marco ha cogido el tren de las ocho. | |
| Spero che ___ bene in albergo. | dormire · voi | abbiate dormito | Espero que hayáis dormido bien en el hotel. | |
| Non credo che loro ___ la verità. | dire | abbiano detto | No creo que hayan dicho la verdad. | |
| Mi sembra che Giulia ___ ieri. | partire | sia partita | Me parece que Giulia se fue ayer. | *essere* verbs agree |
| È strano che nessuno ___. | telefonare | abbia telefonato | Es raro que nadie haya llamado. | |
| Sono felice che voi ___. | venire | siate venuti, siate venute | Me alegro de que hayáis venido. | |
| Credo che i bambini ___ a scuola. | andare | siano andati | Creo que los niños han ido al colegio. | |
| Speriamo che il nonno ___ la lettera. | ricevere | abbia ricevuto | Esperemos que el abuelo haya recibido la carta. | |
| Benché ___ molto, non ha superato l'esame. | studiare · lui | abbia studiato | Aunque ha estudiado mucho, no ha aprobado el examen. | |
| Mi dispiace che tu ___ male. | stare | sia stato, sia stata | Siento que hayas estado mal. | |
| Penso che ___ un errore. | fare · loro | abbiano fatto | Creo que han cometido un error. | |
| È possibile che ___ le chiavi in ufficio. | dimenticare · io | abbia dimenticato | Es posible que haya olvidado las llaves en la oficina. | |
| Non è sicuro che il pacco ___. | arrivare | sia arrivato | No es seguro que el paquete haya llegado. | |
| Dubito che lui ___ quel libro. | leggere | abbia letto | Dudo que haya leído ese libro. | |
| Sembra che i prezzi ___ ancora. | aumentare | siano aumentati | Parece que los precios han subido otra vez. | *aumentare* without an object takes *essere* |
| È il film più bello che io ___ quest'anno. | vedere | abbia visto | Es la película más bonita que he visto este año. | after a superlative → subjunctive (ES indicative) |
| Non penso che ___ bene. | capire · voi | abbiate capito | No creo que hayáis entendido bien. | |
| Spero che non ti ___ niente di grave. | succedere | sia successo | Espero que no te haya pasado nada grave. | |
| Credo che Anna si ___ l'anno scorso. | sposare | sia sposata | Creo que Anna se casó el año pasado. | |
| Mi fa piacere che ti ___ il regalo. | piacere | sia piaciuto | Me alegra que te haya gustado el regalo. | |

# A2 · Future: irregular verbs

> Short stems: *sarò, avrò, andrò, farò, darò, starò, potrò, dovrò, saprò, vedrò, vivrò* · double r: *verrò, vorrò, berrò, rimarrò, terrò*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

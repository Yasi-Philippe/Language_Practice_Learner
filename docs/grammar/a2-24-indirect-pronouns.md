# A2 · Indirect object pronouns

> *mi, ti, gli* (to him), *le* (to her), *Le* (to you, polite), *ci, vi, gli* (to them) — Spanish *le* splits into *gli / le*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = to whom (when the sentence doesn't say); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Cosa regali a Marco? ___ regalo un libro. | | Gli | ¿Qué le regalas a Marco? Le regalo un libro. | *gli* = to him (ES *le*) |
| Luca ha fame: ___ preparo un panino. | | gli | Luca tiene hambre: le preparo un bocadillo. | |
| ___ ho mandato un messaggio, ma Marco non risponde. | | Gli | Le he mandado un mensaje, pero Marco no contesta. | |
| Cosa regali a Giulia? ___ regalo dei fiori. | | Le | ¿Qué le regalas a Giulia? Le regalo flores. | *le* = to her |
| Ho telefonato a mia madre e ___ ho detto tutto. | | le | He llamado a mi madre y le he dicho todo. | |
| Anna è triste: ___ telefono subito. | | le | Anna está triste: la llamo enseguida. | *telefonare a* → indirect: *le telefono* (ES *la llamo*) |
| Giulia ha freddo: ___ presto la mia giacca. | | le | Giulia tiene frío: le presto mi chaqueta. | |
| Marta compie gli anni: ___ compro una torta. | | le | Marta cumple años: le compro una tarta. | |
| Signor Rossi, ___ presento mia moglie. | to you (Lei) | Le | Señor Rossi, le presento a mi mujer. | polite *Le* |
| Vedo i nonni e ___ porto i dolci. | | gli | Veo a los abuelos y les llevo los dulces. | *gli* also = to them |
| I bambini hanno sete: ___ do un po' d'acqua. | | gli | Los niños tienen sed: les doy un poco de agua. | |
| ___ dai il tuo numero? | to me | Mi | ¿Me das tu número? | |
| Il medico ___ ha dato una ricetta. | to me | mi | El médico me ha dado una receta. | |
| ___ scrivo domani. | to you (tu) | Ti | Te escribo mañana. | |
| ___ piace la musica? | to you (tu) | Ti | ¿Te gusta la música? | |
| Chi ___ ha detto questa cosa? | to you (tu) | ti | ¿Quién te ha dicho esto? | |
| Paola, ___ chiedo un favore. | to you (tu) | ti | Paola, te pido un favor. | |
| Il professore ___ spiega la lezione. | to us | ci | El profesor nos explica la lección. | |
| La nonna ___ racconta sempre storie. | to us | ci | La abuela siempre nos cuenta historias. | |
| Ragazzi, ___ porto un regalo. | to you (voi) | vi | Chicos, os traigo un regalo. | |

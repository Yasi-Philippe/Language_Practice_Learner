# A1 · Demonstratives: questo & quello

> *questo, questa, questi, queste* (*quest'* + vowel) · *quello* changes like the article: *quel, quello, quell', quella, quei, quegli, quelle*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = *questo* or *quello*; Spanish = the meaning.
First accepted answer = primary; others are also accepted.

# A2 · Direct object pronouns

> *mi, ti, lo, la* (polite *La*), *ci, vi, li, le* · before the verb · *lo / la* + *ho* → *l'ho* · with a pronoun the participle agrees: *l'ho vista, li ho visti, le ho lette*

Italian sentence with one gap (`___`) → type the missing form. Checked strictly: accents count, capitals don't.
Cue = who or what (when the sentence doesn't say); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

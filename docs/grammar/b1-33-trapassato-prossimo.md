# B1 · Trapassato prossimo

> imperfetto of *avere / essere* + participle: *avevo fatto, ero andato/a* · the past before the past — ES *había hecho* · with *essere* the participle agrees

Italian sentence with one gap (`___`) → type the whole verb (auxiliary + participle). Checked strictly: accents count, capitals don't.
Cue = the verb (and the person when the sentence drops it); Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| Quando sono arrivato, il film ___ da dieci minuti. | cominciare | era cominciato, era iniziato | Cuando llegué, la película había empezado hacía diez minutos. | |
| Prima di quel viaggio, Luca non ___ il mare. | vedere | aveva visto | Antes de aquel viaje, Luca no había visto el mar. | |
| Ho perso il libro che mi ___. | regalare · tu | avevi regalato | He perdido el libro que me habías regalado. | |
| Eravamo stanchi perché ___ tutto il giorno. | lavorare · noi | avevamo lavorato | Estábamos cansados porque habíamos trabajado todo el día. | |
| Quando li ho chiamati, i ragazzi ___. | uscire | erano usciti, erano già usciti | Cuando los llamé, los chicos ya habían salido. | |
| Maria era felice perché ___ l'esame. | superare | aveva superato | María estaba contenta porque había aprobado el examen. | |
| Non sapevo che voi ___ in Messico. | essere | eravate stati, eravate state, foste stati, foste state | No sabía que habíais estado en México. |  |
| Il ladro ___ dalla finestra. | entrare | era entrato | El ladrón había entrado por la ventana. | |
| Mi ha chiesto se ___ la lettera. | ricevere · io | avevo ricevuto | Me preguntó si había recibido la carta. | |
| Siccome ___ tardi, abbiamo preso un taxi. | svegliarsi · noi | ci eravamo svegliati, ci eravamo svegliate | Como nos habíamos despertado tarde, cogimos un taxi. | reflexive: *essere* |
| Lucia mi ha raccontato che cosa ___. | succedere | era successo | Lucía me contó lo que había pasado. | |
| Avevo fame perché non ___ niente. | mangiare · io | avevo mangiato | Tenía hambre porque no había comido nada. | |
| Quando siamo arrivati alla stazione, il treno ___. | partire | era partito, era già partito | Cuando llegamos a la estación, el tren ya había salido. | |
| Gli ___ un messaggio, ma non l'aveva letto. | mandare · io | avevo mandato | Le había mandado un mensaje, pero no lo había leído. | |
| Loro ___ tutto prima di partire. | organizzare | avevano organizzato | Ellos lo habían organizado todo antes de salir. | |
| Prima di venire in Italia, ___ in Spagna? | vivere · tu | avevi vissuto | Antes de venir a Italia, ¿habías vivido en España? |  |
| La festa ___ quando siamo arrivati. | finire | era finita, era già finita | La fiesta había terminado cuando llegamos. | |
| Le ragazze ___ prima di cena. | tornare | erano tornate | Las chicas habían vuelto antes de la cena. | |
| Ho ritrovato le chiavi che ___. | perdere · io | avevo perso, avevo perduto, avevo perse | He encontrado las llaves que había perdido. |  |
| Non riconoscevo la città: ___ molto. | cambiare | era cambiata | No reconocía la ciudad: había cambiado mucho. | *cambiare* without an object takes *essere* |

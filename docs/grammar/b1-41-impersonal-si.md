# B1 · Impersonal and passive si

> *si* + 3rd person = people in general: *si mangia bene* · with a plural object the verb goes plural: *si vendono case* · reflexive verbs: *ci si alza* · adjectives after it go plural: *si è contenti* · compound tenses use *essere*: *si è ballato*

Italian sentence with one gap (`___`) → type *si* and the verb. Checked strictly: accents count, capitals don't.
Cue = the verb; Spanish = the meaning.
First accepted answer = primary; others are also accepted.

| Italian | Cue | Answer (accepted) | Spanish | Notes |
|---|---|---|---|---|
| In Italia ___ bene. | mangiare | si mangia | En Italia se come bien. | |
| Come ___ "gracias" in italiano? | dire | si dice | ¿Cómo se dice "gracias" en italiano? | |
| Da qui ___ il mare. | vedere | si vede | Desde aquí se ve el mar. | |
| Non ___ fumare qui. | potere | si può | Aquí no se puede fumar. | |
| In estate ___ spesso al mare. | andare | si va | En verano se va a menudo a la playa. | |
| In Spagna ___ tardi. | cenare | si cena | En España se cena tarde. | |
| ___ che domani farà caldo. | dire | Si dice | Se dice que mañana hará calor. | |
| ___ subito che è straniero. | capire | Si capisce | Se nota enseguida que es extranjero. | |
| In questo ristorante ___ prenotare. | dovere | si deve | En este restaurante hay que reservar. | *si deve* = hay que |
| Qui ___ case. | vendere | si vendono | Aquí se venden casas. | plural object → plural verb |
| In questo negozio ___ i giornali stranieri. | trovare | si trovano | En esta tienda se encuentran los periódicos extranjeros. | |
| In quel ristorante ___ ottimi vini. | servire | si servono | En ese restaurante se sirven vinos excelentes. | |
| In questa scuola ___ tre lingue. | insegnare | si insegnano | En este colegio se enseñan tres idiomas. | |
| Le chiavi ___ nel cassetto. | tenere | si tengono | Las llaves se guardan en el cajón. | |
| In vacanza ___ tardi. | alzarsi | ci si alza | En vacaciones uno se levanta tarde. | reflexive → *ci si* (never *si si*) |
| Nel weekend ___ con calma. | svegliarsi | ci si sveglia | El fin de semana uno se despierta con calma. | |
| Con questo traffico ___ un'ora per arrivare. | metterci | ci si mette | Con este tráfico se tarda una hora en llegar. | |
| Quando ___ stanchi, si dorme meglio. | essere | si è | Cuando uno está cansado, duerme mejor. | *si è* + plural adjective |
| Ieri ___ molto. | ballare | si è ballato | Ayer se bailó mucho. | compound tenses: *si è* + participle |
| Ieri ___ tanto vino. | bere | si è bevuto | Ayer se bebió mucho vino. | |

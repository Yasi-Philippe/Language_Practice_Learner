# Si mangia bene: the Italian "one"

> **In Italia si mangia bene** = *en Italia se come bien*. This is a structure Spanish speakers already own.

## La regola

- **si** + 3rd person singular: **si dice, si vede, si può**.
- With a plural object the verb goes plural: **si vendono case, si parlano tre lingue**.
- Reflexive verbs: **ci si** (never *si si*) — **ci si alza tardi**.
- Adjectives go plural: **si è contenti, si è stanchi**.
- Compound tenses use **essere**: **si è mangiato bene, si sono vendute tutte le case**.

## Come in spagnolo

- **si mangia** = *se come*; **si vendono case** = *se venden casas*: the same agreement.
- **si può, si deve** = *se puede, hay que*.

## Diverso dallo spagnolo

- Reflexive verbs: Spanish switches to *uno* (*uno se levanta*); Italian says **ci si alza**.
- **si è** + plural adjective: **quando si è stanchi** = *cuando uno está cansado*.
- The past takes **essere**: **si è ballato** = *se bailó*.

## Occhio!

- One thing → singular: **si vende la casa**. Several → plural: **si vendono le case**.
- **si** without an accent; **sì** (yes) with one.

## Curiosità

In Tuscany **si** replaces "we" altogether: **noi si va al mare** — "we're going to the beach", **noi si mangia alle otto**. It sounds like an impersonal sentence with **noi** stuck on the front, and it's everyday Florentine.

## Il trucco

If Spanish uses *se* + verb (*se come, se venden*), Italian does too: **si mangia, si vendono**. If Spanish needs *uno*, Italian needs **ci si**.

# Sounding formal

> **sebbene, qualora, pertanto, bensì**: the words that turn chat into writing. Most of them take the subjunctive.

## La regola

| meaning | everyday | formal |
|---|---|---|
| although | **anche se** + indicative | **sebbene, benché, nonostante, malgrado** + subjunctive |
| if | **se** | **qualora, nel caso in cui** + subjunctive |
| as long as | **basta che** | **purché, a patto che, a condizione che** + subjunctive |
| unless | **se non** | **a meno che (non)** + subjunctive |
| since | **siccome, visto che** | **dal momento che, poiché** |
| so | **quindi** | **pertanto, di conseguenza** |
| but rather | **ma** | **bensì** |
| that is | **cioè** | **ossia, ovvero** |

## Come in spagnolo

- The same register ladder: *aunque → si bien*, *si → en caso de que*, *por eso → por lo tanto*.
- **che io sappia** = *que yo sepa*: the same frozen subjunctive.

## Diverso dallo spagnolo

- **a meno che non** has a **non** that doesn't negate anything: **a meno che non piova** = *a menos que llueva*.
- **qualora** + subjunctive = *en caso de que*; never + indicative.

## Occhio!

- **anche se** takes the indicative, **sebbene** the subjunctive — same meaning, different mood.
- **ovvero** can mean "that is" (like **ossia**) or "or": context decides.

## Curiosità

Italians argue about **piuttosto che**. It means "rather than", but in recent decades many started using it as "or" (**pizza piuttosto che pasta** for "pizza or pasta"). The Accademia della Crusca has warned against the new use since 2002, because "rather than" and "or" can end up meaning opposite things.

## Il trucco

Writing to an office? Swap **se → qualora**, **quindi → pertanto**, **ma → bensì**, **cioè → ossia** — and check every subjunctive.

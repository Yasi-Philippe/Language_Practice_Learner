# Shortcuts in the future

> Irregular futures are just shortened infinitives — and Spanish shortened the very same verbs.

## La regola

| short stem | | double r | |
|---|---|---|---|
| essere | **sarò** | venire | **verrò** |
| avere | **avrò** | volere | **vorrò** |
| andare | **andrò** | tenere | **terrò** |
| potere | **potrò** | rimanere | **rimarrò** |
| dovere | **dovrò** | bere | **berrò** |
| sapere | **saprò** | | |
| vedere | **vedrò** | | |
| vivere | **vivrò** | | |

**fare, dare, stare** keep their **a**: **farò, darò, starò**.

## Come in spagnolo

- Same shortcuts: *habré, podré, sabré* = **avrò, potrò, saprò**.
- **vorrò** and *querré*: both languages doubled the **r**.
- **sarò** = *seré*, **farò** = *haré*, **dirò** = *diré*.

## Diverso dallo spagnolo

- Spanish slips a *d* in: *vendré, tendré, pondré*. Italian doubles the **r** instead: **verrò, terrò**.
- **andare** is regular in Spanish (*iré*) but shortened in Italian: **andrò**.

## Occhio!

- **andrò, vedrò, vivrò** look almost regular but lost an **e**: not *anderò, vederò, viverò*.
- **farò, darò, starò**: not *ferò*.

## Curiosità

Medieval Spanish hesitated before choosing the *d*: old texts have forms like *verné* and *venré* before *vendré* won. Italian took the other road: the **n** melted into the **r**, *ven-rò* → **verrò**.

## Il trucco

If the Spanish future is irregular, the Italian one almost certainly is too — usually in the same verbs.

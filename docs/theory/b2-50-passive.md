# Three ways to say "it was done"

> **essere**, **venire** and **andare** can all build a passive in Italian — each with its own nuance.

## La regola

| auxiliary | meaning | example |
|---|---|---|
| **essere** + participle | is / was done | **la casa è stata venduta** |
| **venire** + participle | gets done (simple tenses only) | **la porta viene chiusa alle otto** |
| **andare** + participle | must be done | **il modulo va firmato** |
| the agent | by | **da**: **scritto da Calvino** |

## Come in spagnolo

- **essere** + participle = *ser* + participle: **fu scoperta da Colombo** = *fue descubierta por Colón*.
- The participle agrees in both: **le case sono state vendute** = *las casas fueron vendidas*.
- Spanish *se* passive = Italian **si** passive: **si vendono case** = *se venden casas*.

## Diverso dallo spagnolo

- The agent takes **da**, not *por*: **scritto da Calvino**.
- **venire** as a passive auxiliary has no Spanish twin: **la cena viene servita alle otto** = *la cena se sirve a las ocho*.
- **andare** + participle means obligation: **va fatto** = *hay que hacerlo*.

## Occhio!

- The compound passive stacks up: **è stata venduta** (**è** + **stata** + participle), like *ha sido vendida*.
- **venire** only in simple tenses: **viene chiusa**, but **è stata chiusa** — never *è venuta chiusa*.

## Curiosità

Patience, in proverb form: **Roma non fu fatta in un giorno** — "Rome wasn't made in a day" — a passive with **essere**, in the passato remoto. Spain's version swaps Rome for Zamora: *No se ganó Zamora en una hora*.

## Il trucco

Spanish *hay que* + verb + object → Italian **va / vanno** + participle: *hay que firmarlo* → **va firmato**; *hay que leerlos* → **vanno letti**.
